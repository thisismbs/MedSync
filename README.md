# MedSync

MedSync adalah sistem manajemen klinik berbasis web yang dibangun menggunakan **Laravel** dan **TailwindCSS**.

## Fitur Utama

- Manajemen data pasien
- Manajemen dokter
- Rekam medis pasien
- Sistem antrian klinik
- Dashboard admin

## Teknologi

- Laravel 11
- Blade
- TailwindCSS
- MySQL
